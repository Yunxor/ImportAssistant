# ImportAssistant

检索并选择性更新同源 FBX 资产的 Unreal Engine 编辑器插件，支持 **AnimSequence、StaticMesh、SkeletalMesh**，减少一份源文件对应多个已有动画或模型时的漏更新。

- 当前版本：`0.2.0`（Beta），单个 `Editor` 模块。
- 已核查环境：Windows、UE 5.8.1 源码、`WGameEditor Win64 DebugGame`；未声明兼容所有 UE 版本。
- 文档修订：2026-11-14。
- 最近一次已记录验证：2026-11-14（Asia/Shanghai），独立 FBX 菜单迁移后插件模块构建成功，现有 **51 项自动化测试通过**；完整 Editor 目标此前于 2026-11-10 构建通过。
- 本次将入口从 Tools 移至独立 FBX 顶级菜单，不设置菜单顺序，不改动窗口业务，并运行现有完整回归；模型测试使用临时可重建几何及专用重导入处理器，真实 FBX 后端、材质/碰撞/LOD 保留、最新窗口视觉和规模性能仍待验收。

本轮菜单迁移（2026-11-14）已编译链接成功。首次链接的 DLL 占用在后台编辑器进程退出后解除，未强制结束进程；重启对应 DebugGame 编辑器后使用新入口。现有回归不包含新菜单点击和视觉验收，这部分仍需在编辑器中确认。

## 快速使用

1. 启动对应配置的项目编辑器，在 **FBX → FBX 资产导入助手** 打开窗口。入口已从 Tools 移至独立的 FBX 顶级菜单，不指定相对其他菜单的顺序。
2. 设置一个或多个 `/Game/...` 或已挂载插件内容目录，勾选要检索的资产类型（默认三类全部启用），启用源路径或名称关键词匹配；需要时配置路径映射、资产存放模板。
3. 拖入 FBX，或点击“添加 FBX…”。等待资产发现、索引和后台匹配完成；结果按 FBX 分组发布，不在匹配尚未完成时执行。
4. 审阅实际命中依据、原来源、脏状态和版本时间。使用单条、分组或表头三态框选择；“选择明确同源项”提供较保守的选择方式。
5. 点击“更新所选…”。插件先加载本次所选资产进行准确预检，来源改绑、覆盖未保存修改或非主来源槽位内容更新时弹出风险确认；原生 Auto Reimport 风险有独立提示。
6. 更新后检查资产、适用的 Skeleton 及其他直接依赖，**由用户自行保存**。可继续勾选下一批，再次执行会生成新计划，无需每批强制重新检索。

## 主要能力

- 按导入源路径、显式路径映射或名称关键词检索三类已有资产，支持同源一对多与多 FBX 冲突提示。
- 每个 FBX 独立分组，虚拟化列表、独立边框、官方类型配色、全局与组内三态选择。
- 仅实际命中路径、映射或关键词的资产进入匹配结果。无关的未知来源只在底部作范围诊断；关键词命中但缺来源槽位的候选留在对应 FBX 组并禁止更新。
- 齿轮菜单控制信息列显隐；**表头 Tooltip 解释字段，单元格 Tooltip 显示具体记录**。
- “是否脏数据”检查目标资产及直接关联依赖包的未保存修改，静态模型不要求 Skeleton；确认后允许覆盖，不再因已确认的脏状态跳过。
- “版本时间”展示**上次导入记录的源 FBX 修改时间（UTC）**，不是重导入操作或 uasset 保存时间。
- 三类名称模板分别生效，例如动画 `AN_Male_Run`、骨骼模型 `SK_Male`、静态模型 `SM_Props_Chair`；按“FBX＋类别”隔离范围，默认保留原目录补查。
- “自动重导入”列按活动目录、规则和真实来源关联评估，不仅检查 Monitor Content Directories 总开关。
- 设置和列显隐通过 UE Config 保存到插件 `Config/ImportAssistant.ini`；CSV 导出不受界面隐藏列影响。

## 使用前必须了解

> 插件仅更新内存，不主动保存资产或签出文件，但这不等于不会覆盖未保存编辑。对脏资产或直接关联依赖确认重导入后，原生导入器可能改变已有内容；不保证可以一次撤销，也不自动回滚已完成项目。

- 检索不批量加载资产；**执行前预检会加载全部本次所选资产并持有相关对象至批次结束**，大批次有内存和耗时成本，建议分批执行。
- 路径范围、模板限制和来源元数据决定检索完整性；“没有匹配”不等于全工程没有同源资产。
- 全局全选跳过多 FBX 来源冲突项；组内全选视为明确选择该组来源，会取消其他组同资产的互斥选择。
- 原生 Auto Reimport、自动保存及第三方工具是独立流程，插件不修改这些开关，也不保证跨工具互斥或完全手动落盘。
- 本轮“FBX 类型支持”指上述三类，**不是所有 FBX 派生对象通用导入**。不直接更新独立 Skeleton、材质、纹理或 PhysicsAsset；场景导入/自定义角色工厂、独立 LOD 工具、Commandlet 和直接修改 uasset 二进制不在本轮范围。
- 自动化通过不等于真实 FBX 数据保留或 UI 视觉验收通过。先在可恢复样本上验证动画附加数据以及模型材质槽、碰撞、LOD、蒙皮等；Legacy 骨骼来源槽位 0/1/2 表示完整内容/几何体/蒙皮，不是 LOD。无法确认的槽位不执行。

## 旧版本配置兼容

旧配置没有资产类型字段时默认三类启用；若要维持动画单类范围，请在“检索范围 → 资产类型”关闭静态和骨骼模型后刷新。旧类别枚举值及模板配置不重命名、不丢弃。CSV 在原 14 列末尾新增“资产类型”“来源槽位内容”，合计 16 列，解析报告的外部脚本应同步检查表头。
